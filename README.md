# redwoodcitydispatch.com

Static landing site for the Redwood City Dispatch newsletter (GitHub Pages). Generated by `site/dispatch/build.py redwoodcity` in the ai-ops repo. Edit there, rebuild, push here. The signup form posts to the n8n webhook `redwoodcity-dispatch-signup`, which creates the beehiiv subscription with custom fields; beehiiv → n8n → Follow Up Boss.
